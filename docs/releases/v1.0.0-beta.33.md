# TorrentLinker 1.0.0-beta.33

Cette bêta remplit l’historique Zen du Profil avec les mois précédant votre première
synchronisation, signale un modèle de l’Assistant que le serveur ne propose pas, et
explique pourquoi l’extension ne se connecte pas à un serveur distant en HTTP.

## Profil

- **Historique Zen antérieur** : toutes les six heures, l’extension lit environ trois
  mois de votre historique Zen c411. Seuls la date et le montant de chaque opération
  quittent c411, jamais leur motif. TorrentLinker remonte depuis le solde actuel pour
  retrouver le solde de fin de chaque jour, ainsi que le gagné et le dépensé quand les
  totaux API du jour sont connus. La courbe Zen couvre ainsi les jours d’avant
  l’installation, au lieu de rester plate.
- Les jours relevés par l’API ne sont jamais remplacés. Les jours reconstitués restent
  vides dans l’historique de synchronisation : rien n’y a été tenté.
- Chaque chiffre de la période se mesure sur les jours qui le connaissent. Les jours
  reconstitués allongent la courbe Zen sans raccourcir les chiffres d’envoi et de
  téléchargement.
- L’extension passe en version 0.5.4. Réenregistrez-la depuis Paramètres → Extension et
  rechargez-la dans le navigateur pour en profiter.

## Assistant

- Quand le modèle configuré n’apparaît pas dans la liste du serveur, « Vérifier le
  contexte » nomme les modèles que le serveur sert. Certains serveurs, comme Strata,
  répondent sous n’importe quel nom : un modèle obsolète faisait retomber la fenêtre de
  contexte à 32 768 tokens, et l’Assistant compactait la discussion à chaque tour sans
  jamais afficher ses cartes.

## Extension

- Sur une adresse distante en HTTP simple, la page de connexion explique que
  l’extension exige HTTPS, par exemple avec `tailscale serve` ou un proxy inverse, au
  lieu d’attendre sans fin.

## Validation et limites

La suite complète passe avec 1 997 réussites et 148 tests optionnels ignorés, avant le
rebasage sur la modification HTTPS de l’extension, qui ne touche qu’une page et la
documentation. Le test navigateur de l’extension réelle lit un historique Zen simulé et
remplit la veille. La forme de l’historique c411 (`createdAt`, `delta`, du plus récent
au plus ancien) vient du code public du site, pas d’une lecture avec un vrai compte.
Cette version reste une bêta.

## English

This beta fills the Profile's Zen history with the months before your first sync,
flags an Assistant model the server does not list, and explains why the companion
cannot connect to a remote server over HTTP.

- **Earlier Zen history**: every six hours the companion reads about three months of
  your c411 Zen ledger. Only each entry's date and amount leave c411, never its reason.
  TorrentLinker walks back from the current balance to each day's closing Zen, plus
  earned and spent when today's API totals are known, so the Zen curve covers the days
  before installation instead of staying flat.
- Days recorded from the API are never replaced, and replayed days stay blank in the
  sync calendar. Each period figure is measured over the days that know it, so
  replayed days lengthen the Zen curve without shortening transfer figures.
- The companion is now version 0.5.4. Save it again from Settings → Companion and
  reload it in the browser.
- **Assistant**: when the configured model is not in the server's model list, "Check
  context" names the models the server serves. Some servers, such as Strata, answer
  under any name, so a stale model fell back to a 32,768-token context and the
  Assistant compacted on every turn without ever showing its cards.
- **Companion over HTTP**: on a remote plain-HTTP address, the connection page explains
  that the companion needs HTTPS (for example `tailscale serve` or a reverse proxy)
  instead of waiting forever.

The full suite passed 1,997 tests with 148 optional skips, before rebasing onto the
companion HTTPS change, which only touches one page and the docs. The real-extension
browser test reads a fake Zen ledger and fills the previous day. The ledger's shape
(`createdAt`, `delta`, newest first) comes from c411's public site code, not a read
with a real account. This is a prerelease; the stable release remains 0.12.2.
