# TorrentLinker 1.0.0-beta.37

Cette bêta embarque son propre Catalogue, remet en partage les correspondances
partielles, ajoute un onglet Animés au centre multimédia et rend le contenu XXX
optionnel.

## Catalogue

- **Catalogue intégré** : l’application contient un Catalogue chiffré d’environ
  247 000 torrents c411, ouvert au premier lancement. Plus besoin d’attendre un premier
  import pour trouver des correspondances.
- **Mise à jour toutes les 4 heures** : les nouveautés de c411 s’ajoutent seules, dans
  le budget de requêtes partagé.
- **Cartes par catégorie** : Zen → Catalogue montre chaque catégorie c411, son nombre
  de torrents face à celui du site, et un bouton ⟳ pour la récupérer entièrement. Les
  torrents supprimés sur c411 sont retirés après une récupération complète.
- **Bandeau Zen dans le pied de page** : il passe en bas à droite, avec une icône ⟳ ;
  la progression du Catalogue reste à gauche.

## Correspondances

- **Correspondances partielles remises en partage** : le torrent est ajouté avec tous
  ses fichiers ignorés, puis démarré, pour partager ce que vous avez déjà.
- **Recherche par taille de fichier** : les torrents déjà en cache sont indexés par
  taille de fichier, pour trouver une sortie même renommée.
- **Épisodes d’un pack** : ils sont vérifiés par lots dans le Catalogue, sans recherche
  sur l’indexeur.

## Médias

- **Onglet Animés**, après Séries : séries, OAV dans des cartes séparées, films et
  genres, à part des Films et Séries. Un animé est reconnu par sa description c411
  (animation japonaise) ou, à défaut, par un dossier nommé Anime ou Manga. Les noms
  comme `Session 01`, `e01` ou `OAV 2` sont lus comme des épisodes.

## XXX

- **Désormais optionnel** : la catégorie XXX de c411 n’apparaît dans les recherches, les
  **Plans** et les types de dossier qu’une fois **Afficher le contenu XXX** activé
  dans les paramètres. Si vos Plans utilisaient XXX, activez ce réglage. Un onglet XXX
  s’ajoute alors au centre multimédia.

## Validation et limites

La suite complète passe. c411 ne liste pas la catégorie XXX par clé d’API : elle reste
alimentée par Torznab et peut compter quelques torrents de moins que le site. Le
plantage du lecteur vidéo lors de changements rapides de piste reste en cours
d’analyse. Cette version reste une bêta.

## English

This beta ships its own Catalogue, reseeds Partial Matches, adds an Anime tab to the
media center and makes XXX content opt-in.

- **Built-in Catalogue**: the app carries an encrypted Catalogue of about 247,000 c411
  torrents, opened on first launch, so matches no longer wait for a first import.
- **Refreshed every 4 hours**: c411's new torrents arrive on their own, within the
  shared request budget.
- **Category cards**: Zen → Catalogue shows each c411 category, its torrent count
  against the site's, and a ⟳ button to fetch it whole. Torrents deleted on c411 are
  removed after a complete fetch.
- **Zen band in the footer**: it moves to the bottom right with a ⟳ icon; Catalogue
  progress stays on the left.
- **Partial Matches reseeded**: the torrent is added with every file skipped, then
  started, to seed what you already have.
- **Find by file size**: cached torrents are indexed by file size, so a renamed release
  can still be found.
- **Pack episodes**: checked in batches against the Catalogue, with no indexer search.
- **Anime tab**, after Series: series, OAVs as cards of their own, films and genres,
  apart from Films and Series. Anime is recognised by its c411 description (Japanese
  animation) or, without one, a folder named Anime or Manga. Names like `Session 01`,
  `e01` or `OAV 2` are read as episodes.
- **XXX is now opt-in**: c411's XXX category appears in searches, **Plans** and folder
  kinds only once **Show XXX content** is on in Settings. If your Plans used XXX, turn
  it on. An XXX tab then joins the media center.

The full suite passes. c411 does not list XXX to API keys, so that category still comes
from Torznab and may count a few torrents fewer than the site. The video player crash
on rapid track changes is still being investigated. This is a prerelease; the stable
release remains 0.12.2.
