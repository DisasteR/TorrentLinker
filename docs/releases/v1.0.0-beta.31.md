# TorrentLinker 1.0.0-beta.31

Cette bêta permet de régler la taille de l’interface du bureau et corrige la page
Recherche, qui restait vide à l’ouverture.

## Interface

- **Paramètres → Général → Taille de l’interface** (de 75 % à 200 %) agrandit ou
  réduit toute l’interface du bureau, en plus de la mise à l’échelle du système. Elle
  aide sur les écrans où cette mise à l’échelle ne convient pas, et s’applique après le
  redémarrage de l’application. Une variable `QT_SCALE_FACTOR` définie par vous reste
  prioritaire.

## Recherche

- À la première ouverture, la page Recherche affiche les dernières sorties dès que les
  filtres sont chargés, comme sur c411, au lieu de rester vide jusqu’au choix d’une
  catégorie. Les visites suivantes gardent l’affichage en cours.
- Une catégorie choisie pendant le chargement de cette première liste est recherchée
  juste après, au lieu d’être ignorée.

## Validation et limites

La suite complète passe avec 1 931 réussites et 148 tests optionnels ignorés. La
taille de l’interface a été vérifiée hors écran (un réglage de 150 % donne un rapport
de pixels de 1,5) mais pas sur un bureau Windows à mise à l’échelle fractionnaire.
Cette version reste une bêta.

## English

This beta lets you set the desktop interface size and fixes the Search page, which
stayed empty when first opened.

- **Settings → General → Interface size** (75% to 200%) enlarges or shrinks the whole
  desktop interface on top of your system's scaling, for screens where that scaling
  does not suit. It applies after restarting the app. A `QT_SCALE_FACTOR` you set
  yourself still wins.
- When first opened, Search lists the latest releases once the filters have loaded, as
  c411's page does, instead of staying empty until a category is chosen. Later visits
  keep what is shown.
- A category chosen while that first list loads is searched right after it instead of
  being ignored.

The full suite passed 1,931 tests with 148 optional skips. The interface size was
checked offscreen (150% gives a device pixel ratio of 1.5), not on a Windows desktop
with fractional scaling. This is a prerelease; the stable release remains 0.12.2.
