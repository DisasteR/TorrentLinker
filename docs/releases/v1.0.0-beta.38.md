# TorrentLinker 1.0.0-beta.38

Cette bêta rend la lecture 4K fluide, corrige les couleurs HDR, lit un fichier pendant
son téléchargement et permet à l’assistant de choisir la version que vous désignez.

## Médias

- **Lecture 4K fluide** : les images trop grandes pour le lecteur sont réduites hors du
  fil de l’interface. Un film 4K à 24 images/s n’est plus saccadé (environ 20 images/s
  auparavant).
- **Plus d’à-coups toutes les 30 à 50 s** : pendant une vidéo, l’actualisation du
  partage, celle du Catalogue et l’analyse des dossiers Médias attendent la fin de la
  lecture.
- **HDR10 corrigé** : les reflets ne sont plus écrêtés et les rouges très saturés ne
  laissent plus de taches noires.
- **Aperçu pendant le téléchargement** : sur desktop, l’aperçu d’un téléchargement
  qBittorrent séquentiel lit le fichier à mesure qu’il arrive, comme l’aperçu de
  qBittorrent. Quand la lecture rattrape le téléchargement, elle attend les morceaux
  suivants puis reprend.

## Assistant

- **Choisir une version** : quand vous désignez une ou plusieurs versions d’une
  recherche (« prends la ROMKENT »), l’assistant ne garde que celles-ci avant de les
  mettre en file et de les envoyer. Un nom absent de la recherche est refusé au lieu
  d’être deviné.

## Bibliothèque

- **Progression de la recherche d’orphelins** : le pied de page indique l’élément en
  cours (« Recherche 94/822 : … »), le nombre d’échecs et une barre de progression.

## Validation et limites

La suite complète passe. Dans le lecteur web, l’aperçu d’un téléchargement reste une
portion fixe jusqu’à son actualisation. Cette version reste une bêta.

## English

This beta makes 4K playback smooth, fixes HDR colours, plays a file while it downloads
and lets the Assistant pick the release you name.

- **Smooth 4K playback**: frames too large for the player are reduced off the interface
  thread. A 4K film at 24 fps no longer stutters (it played at about 20 fps before).
- **No more hitch every 30–50 s**: while a video plays, the Seeding refresh, the
  Catalogue refresh and the Media folder rescan wait for it to stop.
- **HDR10 fixed**: highlights no longer clip, and very saturated reds no longer leave
  black blotches.
- **Preview while downloading**: on desktop, previewing a sequential qBittorrent
  download plays the file as it arrives, like qBittorrent's preview. When playback
  catches up with the download, it waits for the next pieces, then carries on.
- **Pick a release**: when you name one or more releases from a search ("take the
  ROMKENT one"), the Assistant keeps only those before queueing and sending them. A
  name that is not in the search is refused instead of guessed.
- **Orphan search progress**: the footer shows the item being searched ("Searching
  94/822: …"), how many failed, and a progress bar.

The full suite passes. In the web player, a download preview stays a fixed portion until
refreshed. This is a prerelease; the stable release remains 0.12.2.
